# Test Project

A Node.js application built with TypeScript and Next.js.

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Next.js
- **Other:** [dotenv](https://github.com/motdotla/dotenv) for environment variables

## Getting started

1. Install dependencies:

```bash
npm install
```

2. Create a `.env` file in the project root for local secrets (do not commit it).
